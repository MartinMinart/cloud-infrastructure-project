# WinSCP — руководство по работе с проектом

## Назначение

WinSCP — графический SFTP-клиент для копирования файлов между локальным ПК и виртуальными машинами Cloud.ru.

## Ключ и инструменты

Для подключения используется ключ:

`C:\Users\MI\.ssh\id_ed25519.ppk`

Это PuTTY-формат, созданный из OpenSSH-ключа `id_ed25519` через PuTTYgen.

| Инструмент | Для чего |
|---|---|
| PuTTYgen | Конвертация SSH-ключа из OpenSSH в PuTTY (.ppk) |
| WinSCP | Работа с файлами через SFTP/SSH в графическом интерфейсе |
| pscp.exe | Консольный вариант SCP для копирования файлов из командной строки |

## 1. Подготовка ключа

1. Установить PuTTYgen.
2. Открыть **Conversions** → **Import key**.
3. Выбрать файл: `C:\Users\MI\.ssh\id_ed25519`.
4. Нажать **Save private key**.
5. Сохранить как: `C:\Users\MI\.ssh\id_ed25519.ppk`.

## 2. Подключение к серверу через WinSCP

2. В поле **New Site** заполнить:

   - **Host name:** `213.171.26.123`
   - **User name:** `user1`
   - **Private key file:** `C:\Users\MI\.ssh\id_ed25519.ppk`
3. Нажать **Login**.

## 5. Основные действия

| Действие | Как сделать |
|---|---|
| Скачать файл | Выделить файл → перетащить в левую панель (локальный ПК) |
| Загрузить файл | Выделить файл на локальном ПК → перетащить в правую панель (сервер) |
| Редактировать | ПКМ → **Edit** |
| Создать папку | ПКМ → **New** → **Directory** |
| Удалить файл | ПКМ → **Delete** |
| Синхронизировать | **Commands** → **Synchronize** |

### Навигация

- Левая панель = локальный ПК
- Правая панель = сервер

## 6. Принцип работы

WinSCP работает только пока соединение активно:

1. Открыть WinSCP.
2. Подключиться к нужной сессии.
3. Выполнить работу с файлами.
4. Закрыть WinSCP после завершения.

Файлы на сервере не удаляются после закрытия сессии; они остаются на удалённой машине.

Чтобы открыть сохранённую сессию, нужно:

- Запустить WinSCP
- Выбрать сохранённую сессию, например `devops-main`
- Нажать **Login**

## 9. Как подключиться к новой ВМ в WinSCP

1. Открыть WinSCP.
2. Нажать **New Site**.
3. Заполнить:
   - **Host name:** IP из таблицы выше
   - **User name:** `user1`
   - **Private key file:** `id_ed25519.ppk`
4. Нажать **Save** и дать понятное имя сессии.
5. Нажать **Login**.

**Рекомендация:** сохранить все 4 подключения, чтобы быстро переключаться между серверами.

## 10. Важно: что нельзя делать

- ❌ Не редактировать `.env`, `kubeconfig`, `secrets.yaml` через WinSCP без необходимости
- ❌ Не копировать папку `cloud-private/` в локальный проект
- ❌ Не загружать чувствительные данные напрямую в GitHub
- ❌ Не хранить пароли или ключи в открытых файлах проекта
